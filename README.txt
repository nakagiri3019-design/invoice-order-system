============================================================
  請求書・発注書作成システム v1-5（v16）
  テンプレート1・2・3 ReportLab完全対応版
============================================================

■ 起動方法
  start_invoice_system.bat をダブルクリック
  → ブラウザで http://127.0.0.1:8600 を開く

■ テンプレート一覧
  テンプレート1：スタンダード（モノクロ・シンプル）
    - 基本的な請求書・発注書向け
  テンプレート2：ネイビー×ゴールド高級版（★Premium）
    - AI開発・コンサル・制作案件など見栄え重視の案件向け
    - 請求書・発注書・見積書・納品書 4書類対応
  テンプレート3：白黒すっきり・枠付き明細重視版
    - 物販・卸売・納品書など品目・数量・単価を見やすくしたい案件向け
    - 請求書・発注書・見積書・納品書 4書類対応

■ 書類種別
  請求書・発注書・見積書・納品書

■ フォルダ構成
  app.py                    ← メインサーバー（Python）
  requirements.txt          ← 依存パッケージ一覧（reportlab のみ）
  start_invoice_system.bat  ← 起動スクリプト（Windows）
  config.json               ← 発行元・振込先・角印設定（自動生成）
  static/                   ← 角印画像置き場（seal.png）
  output/                   ← PDF出力先（自動生成）
  Procfile                  ← Render用起動設定
  render.yaml               ← Renderデプロイ設定

■ 依存パッケージ
  reportlab==4.2.2 のみ（WeasyPrint不要）

■ Renderデプロイ
  GitHub にpush → Render で自動デプロイ
  PORT環境変数・0.0.0.0バインド済み

■ 注意事項
  ・WeasyPrintは不要です。ReportLabのみで全テンプレート動作します。
  ・テンプレートのデザインは固定です。AIに都度生成させません。
  ・PDF出力前に自動レイアウトチェックが動作します。
